## 🎮 About Project Retrac

**Project Retrac** is a Fortnite OG emulator project built around the classic Fortnite experience. With a focus on legacy emulation, preservation, and dedicated launcher development, Retrac aims to bring enthusiasts closer to the era that made Fortnite memorable.

The project explores the technical challenges of legacy game compatibility while providing a central place for project information, launcher access, and development updates.

> *Some experiences never get old. Project Retrac is built around keeping the spirit of the OG era alive.*

Whether you're interested in classic Fortnite, legacy game builds, or emulation technology, Retrac is a project dedicated to exploring that history.
